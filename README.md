# Anti-Caps
A small system tray app that turns off capslock as soon as it is turned on.

## Usage and features
This is a very simple app I made to stop my friends from constantly turning on my capslock. It detects if capslock is on, and if so, turns it off again.

Right-clicking the system tray icon will give you two options, Pause and Exit. Exit is pretty self-explanatory; it causes the app to quit. Pause is a toggleable option that will deactivate the capslock blocking while active, in case you actually do want to use capslock (but who does?).

## Installation

The app does not require any installation; just download and run the .exe, however I recommend putting the .exe in your startup folder using the steps below so the utility will run when your computer turns on:
1. Press Win+R.
2. Type `shell:startup` and hit enter.
3. Place the .exe in the folder that opens.
